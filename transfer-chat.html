01 / HB TRANSFER
Files without the fuss

Make the jump
between devices.

HB Transfer is a file-sharing project focused on moving files between Windows and Android over local Wi-Fi. A practical bridge from your desktop to your mobile device.

In development · Local Wi-Fi MVP
See availability and next steps ↗
  1. 01

    A connection close to home.

    The intended workflow brings devices together on the same local Wi-Fi network.

  2. 02

    Bring the files that matter.

    Designed around sharing different file types, from documents to media and archives. Supported sizes and reliability still need validation.

  3. 03

    Windows meets Android.

    A desktop-to-mobile direction, with an early MVP under development. Public release details are not yet confirmed.

02 / HB CHAT
A connection worth building

Your next message.
A little more direct.

HB Chat explores peer-to-peer messaging and file sharing on Android. Connect through the project's peer and invite controls, then put the conversation to the test.

Android 10+ · Development testing
Check the testing status ↗
  1. 01

    Peer-to-peer by design.

    The project includes a messaging interface and peer connection controls. Internet access is needed for its existing PeerJS signaling.

  2. 02

    More than a message.

    The documented test flow covers sending text, sending a small file and saving a received file on Android.

  3. 03

    Real devices. Real testing.

    Live messaging, reconnection and background behavior still require device testing. A successful build alone does not confirm reliability.
